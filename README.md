# UltraQuery

UltraQuery is a Python/C++ CSV analytics library. Python provides the public
interface, the native C++ engine handles the existing terminal data views, and
pandas/matplotlib provide structured analysis and plots.

## Architecture

```text
CSV -> Python UltraQuery -> ctypes -> C++ engine
                  |
                  +-> compact CSV context -> optional AI provider
                  +-> WebCmd OmniSearch -> external research
```

The C++ functions currently print columns and tables to stdout and return no
structured data. The Python wrapper preserves that behavior for the existing
view commands. Structured AI-ready context is generated by `ai_tools.py` with
pandas instead of pretending that C++ already returns JSON.

## Installation on Windows

Activate the project environment, install the Python package, and ensure the
native engine DLL is present in `UltraQuery_core/engine_lib`:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

The project dependencies are pandas and matplotlib. WebCmd is an external CLI;
it is not installed by this Python package.

## Local CSV context

This command reads the CSV in chunks and returns row count, column names,
numeric min/max/mean values, and a small sample. It does not send the complete
CSV to an AI model:

```powershell
python -m UltraQuery_core.cli --context data.csv
```

## WebCmd integration

UltraQuery integrates WebCmd as an external research layer. It uses the
verified command:

```text
webcmd omnisearch research "your query" -f json
```

For example:

```powershell
webcmd --help
webcmd omnisearch research "electric vehicles" -f json
python -m UltraQuery_core.cli --web-search "electric vehicles"
```

On Windows, the Python adapter discovers the installed `webcmd.cmd` launcher.
Set `WEBCMD_EXECUTABLE` only if WebCmd is installed at a non-standard path. Set
`WEBCMD_TIMEOUT` to change the default 60-second timeout.

## Optional AI model

There is no provider-specific default and no hard-coded API key. The `ask`
command calls an OpenAI-compatible chat endpoint only when these environment
variables are configured:

```powershell
$env:ULTRAQUERY_AI_ENDPOINT = "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions"
$env:ULTRAQUERY_AI_API_KEY = "your-gemini-api-key"
$env:ULTRAQUERY_AI_MODEL = "gemini-3.6-flash"
```

For Gemini's OpenAI-compatible endpoint, use `gemini-3.6-flash` as the model
value. If a provider reports the resource form `models/gemini-3.6-flash`,
UltraQuery removes the `models/` prefix automatically. The current adapter uses
the Chat Completions-compatible interface; Gemini's separate Interactions API
would require a different request and response adapter and is not enabled by
this command.

Then run:

```powershell
python -m UltraQuery_core.cli ask data.csv "Summarize the important patterns"
python -m UltraQuery_core.cli --with-web ask data.csv "Analyze the data and compare it with current external research"
```

The model receives the user question, compact local CSV context, and optional
WebCmd result. WebCmd is integrated into the UltraQuery application, not into
GitHub Copilot's internal model.

## Existing CLI operations

The original view and plotting options remain available:

```powershell
python -m UltraQuery_core.cli --columns data.csv
python -m UltraQuery_core.cli --view --file data.csv --limit 20
python -m UltraQuery_core.cli --plot --file data.csv --xAxis category --yAxis value --type bar
```

For automatic plotting, UltraQuery detects a categorical column and the first
numeric column:

```powershell
python -m UltraQuery_core.cli --auto-plot --file data.csv --type bar
```

For a grouped comparison chart, the CSV needs at least two numeric columns.
Use comma-separated column names when selecting them:

```powershell
python -m UltraQuery_core.cli --compare --file metrics.csv --xAxis month --yAxis sales,cost
```

The comparison command aggregates numeric values by the selected category and
draws one series per numeric column. Automatic plotting requires at least one
numeric column; arbitrary text-only CSVs cannot produce a numeric chart.

## Multi-dataset intelligence workflow

Use `analyze` when you have several CSV datasets. It compares shared numeric
columns and sends one compact combined context to the configured AI model:

```powershell
python -m UltraQuery_core.cli analyze sales-2025.csv sales-2026.csv `
    --question "Compare both datasets and explain the biggest changes"
```

Use `--payload-only` to inspect the structured comparison without calling an AI
provider:

```powershell
python -m UltraQuery_core.cli analyze sales-2025.csv sales-2026.csv --payload-only
```

If a CSV contains a column with public `http://` or `https://` links, WebCmd can
fetch a bounded number of those pages and include their titles and extracted
content:

```powershell
python -m UltraQuery_core.cli analyze products.csv reviews.csv `
    --scrape-urls --max-urls 5 --payload-only
```

For the full workflow with WebCmd research and Gemini:

```powershell
python -m UltraQuery_core.cli analyze products.csv reviews.csv `
    --scrape-urls --max-urls 5 --with-web `
    --question "Compare the datasets and use the linked pages to explain the market context"
```

Visualize common numeric metrics across datasets:

```powershell
python -m UltraQuery_core.cli multi-plot sales-2025.csv sales-2026.csv -y sales
```

URL fetching is read-only, public-URL oriented, limited by `--max-urls`, and
uses WebCmd's extracted text rather than sending full web pages to the model.

## Complete command cookbook

Run these commands from the project root after activating `.venv`:

### Setup and help

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m UltraQuery_core.cli --help
```

The installed console command is also available:

```powershell
ultraquery --help
```

### AI configuration

Configure the AI provider only in the current PowerShell session. Never commit
or paste the API key into source files, README files, screenshots, or chat:

```powershell
$env:ULTRAQUERY_AI_ENDPOINT = "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions"
$env:ULTRAQUERY_AI_API_KEY = "YOUR_GEMINI_API_KEY"
$env:ULTRAQUERY_AI_MODEL = "gemini-3.6-flash"
```

Safe configuration check that does not print the key:

```powershell
if ($env:ULTRAQUERY_AI_API_KEY) { "AI key configured" } else { "AI key missing" }
Write-Host $env:ULTRAQUERY_AI_ENDPOINT
Write-Host $env:ULTRAQUERY_AI_MODEL
```

### Local CSV analysis

```powershell
# Compact JSON context: rows, columns, numeric min/max/mean, sample rows
python -m UltraQuery_core.cli --context data.csv

# View columns through the native C++ engine
python -m UltraQuery_core.cli --columns data.csv

# View rows/data with an optional limit
python -m UltraQuery_core.cli --view --file data.csv --limit 20
python -m UltraQuery_core.cli --column_data data.csv --limit 20

# Render a native C++ dataframe-style table
python -m UltraQuery_core.cli --DataFrame data.csv --limit 20
```

### AI analysis

```powershell
# Local CSV context plus Gemini answer
python -m UltraQuery_core.cli ask data.csv "Summarize the important patterns"

# Local CSV context plus WebCmd research plus Gemini answer
python -m UltraQuery_core.cli --with-web ask data.csv `
    "Analyze this data and compare it with current external research"
```

### WebCmd research

```powershell
# Check the installed WebCmd surface
webcmd --help
webcmd list -f json
webcmd omnisearch research --help

# Direct WebCmd research
webcmd omnisearch research "electric vehicle battery technology" -f json

# The same research through UltraQuery
python -m UltraQuery_core.cli --web-search "electric vehicle battery technology"

# Fetch a public page directly through WebCmd
webcmd web fetch --url https://example.com -f json
```

### Automatic and explicit charts

```powershell
# Automatically choose a meaningful column and chart type
python -m UltraQuery_core.cli --auto-plot --file data.csv --type auto

# Force an automatic bar chart
python -m UltraQuery_core.cli --auto-plot --file data.csv --type bar

# Explicit charts: bar, pie, line, scatter, histogram
python -m UltraQuery_core.cli --plot --file data.csv `
    --xAxis category --yAxis value --type bar

python -m UltraQuery_core.cli --plot --file data.csv `
    --xAxis date --yAxis sales --type line

# Compare multiple numeric columns in one CSV
python -m UltraQuery_core.cli --compare --file metrics.csv `
    --xAxis month --yAxis sales,cost
```

### Smart futuristic dashboard

The dashboard creates KPI cards, top-value rankings, metric relationships,
status/category distribution, and an evidence/AI panel:

```powershell
# Local data dashboard
python -m UltraQuery_core.cli --dashboard --file data.csv `
    --output dashboard.png

# Dashboard with URLs from the CSV fetched through WebCmd
python -m UltraQuery_core.cli --dashboard --file products.csv `
    --scrape-urls --max-urls 3 --output products_dashboard.png

# Dashboard with WebCmd evidence and AI summary
python -m UltraQuery_core.cli --dashboard --file products.csv `
    --scrape-urls --max-urls 3 --with-web `
    --question "Explain the most important product and market signals" `
    --output products_ai_dashboard.png

# Open a generated image on Windows
start dashboard.png
```

### Multiple CSV datasets

```powershell
# Create a list of all CSV files in a folder
$files = Get-ChildItem -LiteralPath "C:\data\archive" -Filter "*.csv" |
    Select-Object -ExpandProperty FullName

# Compare all files without an AI call
python -m UltraQuery_core.cli analyze $files --payload-only `
    --question "Compare these datasets"

# Compare all files and generate an AI answer
python -m UltraQuery_core.cli analyze $files `
    --question "Compare all datasets and explain the biggest changes"

# Compare all files with WebCmd research
python -m UltraQuery_core.cli analyze $files --with-web `
    --question "Compare the datasets and explain the external context"

# Compare datasets while scraping public URLs found inside them
python -m UltraQuery_core.cli analyze $files --scrape-urls --max-urls 5 `
    --payload-only --question "Summarize the linked evidence"

# Visual comparison of common numeric metrics across files
python -m UltraQuery_core.cli multi-plot $files -y frp
```

### Error and no-AI testing

```powershell
# Test the complete structured payload without an AI key
python -m UltraQuery_core.cli analyze data1.csv data2.csv --payload-only

# Test missing-file handling
python -m UltraQuery_core.cli --context missing.csv

# Test invalid or unsupported chart input
python -m UltraQuery_core.cli --auto-plot --file data.csv --type unknown
```

`--payload-only` is the safest way to inspect what would be sent to an AI
provider. It lets you validate local statistics, dataset comparisons, and URL
evidence without making an AI request.

## demo flow

1. Start with a CSV and a question.
2. UltraQuery creates compact local context.
3. WebCmd OmniSearch retrieves external research when requested.
4. The configured AI endpoint combines both inputs into an answer.
5. Existing deterministic plotting can visualize selected columns.

If the AI environment variables are not configured, the project honestly stops
with a configuration message; it does not claim that an AI model was used.

## Current limitations

- The native C++ view functions print text rather than returning structured Python values.
- The AI endpoint must be OpenAI-compatible and supplied by the user.
- WebCmd must be installed separately and available to the Windows environment.
- The plotting API remains deterministic; the model does not autonomously execute arbitrary code.
